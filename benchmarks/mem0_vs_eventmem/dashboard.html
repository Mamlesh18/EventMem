Method

Fairness and what this does not measure. Both sides use sentence-transformers all-MiniLM-L6-v2 and the same Redis instance. mem0 runs with infer=False, which skips its LLM fact-extraction step — a deliberate concession, since charging it an LLM call per write would inflate EventMem's advantage on something this benchmark is not about. The cost is that mem0's headline features (LLM-curated memory, contradiction detection, memory updating, graph memory) are switched off, and EventMem has no equivalent of any of them. This measures retrieval quality and propagation only.
